# Changelog

## 0.1.0 (2026-10-24)

First release.

- Conversion graph with cheapest-route planning (up to 3 steps), terminal and direct-only edges
- Images, PDF, data (JSON/JSONL/YAML/TOML/XML/CSV/TSV), XLSX, DOCX/Markdown/HTML/TXT, archives built in
- Optional FFmpeg, LibreOffice and Pandoc engines
- CLI: `convert`, `formats`, `route`, `engines`, `pdf merge|split|compress`, `watch`, `serve`
- Local drag-and-drop web UI with a format ring, options and parallel conversions
- Python API and `convertly.converters` plugin entry point
- Hardened against hostile inputs (see SECURITY.md)
