# Code of Conduct

We want convertly to be a friendly project for everyone.

- Be kind and patient; assume good intent.
- Critique code and ideas, not people.
- No harassment, discrimination, sexualized content, personal attacks or doxxing.
- Respect maintainers' decisions on scope; disagree in writing and move on.

Maintainers may remove content and block participants who don't follow this. Report problems privately to
marketing@atomesus.com. This code is inspired by the Contributor Covenant (https://www.contributor-covenant.org).
